[[tests-reactive-netty-event-loops]]
= Reactive Netty Event Loops Tests

This directory contains tests for verifying Netty event loop configurations in a reactive Spring Data Aerospike project.

Each test class activates a different event loop configuration via the `demo.eventloop.type` property
and verifies that the expected transport is used.

== Prerequisites

- JDK 17
