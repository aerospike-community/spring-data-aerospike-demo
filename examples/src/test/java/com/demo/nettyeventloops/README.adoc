[[tests-netty-event-loops]]
= Netty Event Loops Tests

This directory contains tests for verifying Netty event loop configurations in a Spring Data Aerospike project.

Each test class activates a different event loop configuration via the `demo.eventloop.type` property
and verifies that the expected transport is used.

== Prerequisites

- JDK 17
